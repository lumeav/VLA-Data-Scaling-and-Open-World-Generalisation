# Presentation Template: MSI-Seminar WS2026/27

Beamer template in the HTWG design.

- Fill in the details (team, names, title, date, title image) at the top of `main.tex`.
- References go in `refs.bib`.
- Overleaf: upload the ZIP, compiler pdfLaTeX. Locally: `latexmk -pdf main.tex`
- Slides with notes: use `\note{...}` and enable `\setbeameroption{show notes}`.
